# DISCIPLINE 30
Бесплатная локальная PWA, без API и внешних зависимостей.

## Установка
1. Создай репозиторий GitHub и загрузи содержимое этой папки в корень. Не загружай резервные копии с личными данными.
2. Settings → Pages → Deploy from a branch → main / root.
3. Открой выданный HTTPS-адрес на iPhone в Safari → Поделиться → На экран «Домой».
4. На компьютере открой тот же адрес.

Данные хранятся отдельно в каждом браузере. Автоматической облачной синхронизации и push нет. Для переноса используй Настройки → резервная копия JSON → восстановить на другом устройстве (заменяет данные, не объединяет). Для напоминаний используй приложение «Напоминания» iPhone.

Для локальной проверки: python -m http.server 8000, открыть http://localhost:8000. Офлайн-кэш появляется после первой успешной загрузки по HTTPS или localhost.
